# Журнал замеров

Факт из транскриптов Claude Code, снимается `node scripts/ctx.mjs --log "<кирпич>"`.

- **BASE** — окно на первом ответе: цена «просто открыть проект», до первого слова дизайнера.
- **PEAK** — максимум занятого окна за сессию.
- **ЗАДАЧА** — сколько добавил последний запрос.

| Кирпич | Сценарий | BASE | PEAK | ЗАДАЧА |
|---|---|---|---|---|
| v1 (для сравнения) | «пересобрать шаблон» в product-design-starter | 51 612 | 88 608 | +26 382 |

## Из чего складывается BASE

Статический подсчёт файлов v1 (AGENTS.md 2 400 + frontmatter скиллов 2 100 + команды 570 ≈ 5 000)
объясняет **десятую часть** реального BASE. Остальное — то, что в файлах репо не видно:

- системный промпт Claude Code,
- описания инструментов подключённых MCP-серверов (Atlassian Rovo — ~40 инструментов),
- список скиллов (20 шт.) и сабагентов (8 шт.) с описаниями,
- память проекта.

Вывод для плана: экономия только на прозе AGENTS.md — это борьба за 5% от BASE.
Разложить BASE на слагаемые и понять, чем из них мы вообще управляем, — задача К0.
| К0 · нулевая точка | что это за проект? | 58 081 | 64 378 | +6 297 |

## Плагины (замер `claude plugin details`, 2026-08-26)

| Плагин | Скиллов | Always-on | Худший on-invoke | Статус |
|---|---|---|---|---|
| superpowers 6.3.0 | 14 | ~688 | ~11 800 (`subagent-driven-development`) | **удалён 2026-08-26** |

| frontend-design | — | — | — | был выключен |

`claude plugin details <name>` печатает инвентарь и прогноз стоимости — дешёвый способ
оценить любой плагин до установки. Always-on платится всегда, on-invoke — при каждом
срабатывании скилла: плагин может не давить на старт и при этом внезапно съесть окно посреди задачи.

Больше половины окна — **описания встроенных инструментов**. Для сравнения, весь кит v1
(AGENTS.md + 20 скиллов) — это ~5k. Мы собирались резать 5k, не замечая 32k рядом.

### Что сколько стоит (headless-замеры, повторы ±2 токена)

| Конфигурация | BASE |
|---|---|
| как есть | 49 949 |
| без MCP-серверов (`--strict-mcp-config`) | 47 936 |
| дизайнерский набор `--tools` + MCP, **без** ToolSearch | 50 665 |
| дизайнерский набор `--tools` + MCP, **с** ToolSearch | 26 150 |
| только `Read,Bash`, без MCP | 15 302 |

**ToolSearch** — механизм отложенной загрузки: с ним схемы MCP не сидят в контексте,
а подтягиваются по требованию. Без него сорок инструментов Atlassian грузятся целиком (+26k).
Сами MCP-серверы при живом ToolSearch стоят всего ~2.4k — на них экономить нечего.

### Рычаг, который едет с шаблоном

Набор инструментов задаётся только флагом `--tools` при запуске (поле `tools` в settings.json
игнорируется — проверено, 49 948). Зато **`env` в `.claude/settings.json` работает** и не зависит
от способа запуска:

### К1 пересобран по образцу xsolla-super-app

Там `AGENTS.md` лежит в `docs/architecture/` и помечен «do not read end-to-end for routine tasks»,
роутер `__ai/ROUTER.md` читается «when the task path is unclear» — always-on остаётся только `CLAUDE.md`.
Я же сначала импортировал `AGENTS.md` в `CLAUDE.md` и тем прибил его в контекст навсегда.

| Вариант | BASE | Цена кита |
|---|---|---|
| `CLAUDE.md` → `@AGENTS.md` (импорт) | 32 598 | 446 |
| `CLAUDE.md` 3 строки + `AGENTS.md` роутером по требованию | 32 319 | **237** |

Два урока из поведенческого теста (`claude -p "привет, давай поработаем"`):

1. **«Читай роутер, если путь неясен» не срабатывает.** Агент почти никогда не признаёт путь
   неясным: он не спросил про режим, а полез разбирать незакоммиченный diff. Правило первого
   хода должно жить в харнессе (SessionStart hook), а не в прозе.
2. **Агент правит машинные файлы.** Он удалил из `settings.json` строку, гасящую superpowers,
   решив, что она мёртвая — верно для этой машины, неверно для любого другого дизайнера.
   Нужен PreToolUse-guard на `.claude/**`, а не абзац про «машинные файлы».
3. Цена свободного хода: «привет, давай поработаем» — **+15 763 токена**, PEAK 48 089.
   Без явного первого шага агент читает всё подряд.
